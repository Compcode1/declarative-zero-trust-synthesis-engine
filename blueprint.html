1. Agentic Patterns (The ReAct Framework)
The AI Systems Engineering Standard (Yao et al.) Developed by researchers at Princeton and Google Brain, the ReAct (Reasoning and Acting) methodology prevents language models from guessing in a vacuum by forcing them to alternate between reasoning steps and checking real external data sources.
How I Applied It in My System Directive In Phases 1 and 2, The AI Engine is forbidden from guessing my Entra ID Tenant ID, Azure Subscription ID, Resource Group, or Subject Claim (such as my Code Repository and Branch spelling). 2. Bounded Autonomy (OWASP Top 10 for LLMs: LLM08)
The AI Systems Engineering Standard (OWASP LLM08: Excessive Agency) The global OWASP application security standard for artificial intelligence, which mandates strict permission boundaries so an AI model cannot exercise unchecked agency or run destructive commands across enterprise systems.
How I Applied It in My System Directive The AI Engine has zero direct network access to my Entra ID Tenant ID or Azure Subscription ID and is locked inside hard rules inside my System Directive: referencing and binding existing live resources in place on Brownfield (Existing) builds without modifying or overwriting live assets, enforcing single-asset Data-Plane Roles (blocking Owner and Contributor Roles), and staging a guided Azure Portal MFA Handoff whenever a Data-Plane Role assignment requires interactive MFA.
3. Human-in-the-Loop Governance (NIST AI RMF 1.0)
The AI Systems Engineering Standard (NIST AI Risk Management) The U.S. federal standard establishing the "Govern" function, requiring continuous human oversight, risk control, and clear human accountability at every critical decision point in a high-impact AI system.
How I Applied It in My System Directive My System Directive forbids The AI Engine from skipping ahead or stacking manual steps. The State Machine must halt at every single phase, from locking in the 5 Build Coordinates and extracting the OpenID Connect (OIDC) Subject Claim to running the live `.yml` Validation Bridge workflow file on my Execution Agent and checking Azure Portal Monitoring Metrics (Total Service API Hits) on my Data-Plane Asset, waiting for my explicit verification before advancing.
4. Cognitive Circuit Breaking & Continuous Evolution
The AI Systems Engineering Standard (Huang et al.) Grounded in foundational AI reliability research, cognitive circuit breaking stops language models from drifting off their instructions and repeating false guesses ("hallucination spirals") during multi-turn troubleshooting sessions.
How I Applied It in My System Directive My System Directive enforces continuous improvement in Phase 7 while keeping routine bug logging separate from emergency circuit breaking across every phase. Verified fixes during the Standard Patch Loop (Iterations 1 to 3) are logged immediately in the Defect & Patch Ledger (DPL) with a full-file State Re-Sync of my IaC Payload.
