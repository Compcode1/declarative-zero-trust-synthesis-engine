Featured • Project 04: Cloud Identity for Construction AI

16 November 2026 • Upload coordination / Analysis coordination

Learning objective: apply separate workload identities to two supporting jobs in a construction video/AI scenario.

Implemented scope: own-role and configuration access passed; listing, opposite-secret reads and opposite-role admission were denied for both jobs, with twelve selected CloudTrail correlations and a team-facing handoff.

Project 03: Role Admission and Configuration Isolation

15 November 2026 (PST) • Two OIDC contexts / Opposite-role admission tests

Learning objective: test which role a worker can enter before testing which configuration it can read.

Implemented scope: both own-role exchanges and own configuration reads/descriptions succeeded. Opposite-role WebIdentity requests, listing and cross-secret reads were denied. The case study presents twelve selected correlations across fourteen recorded event IDs.

Project 02: Two-Worker Configuration Isolation

15 November 2026 • Two repositories / Two roles / Two secrets

Learning objective: test each worker’s own configuration access and explicit adjacent-secret denials.

Implemented scope: two GitHub Actions workers with distinct role and secret bindings. Both own reads/descriptions succeeded; enumeration and opposite-secret reads received expected authorization denials, with eight selected normalized CloudTrail records.
